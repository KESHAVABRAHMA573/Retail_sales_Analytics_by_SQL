# 🛒 Retail Sales Data Analysis (SQL Project)

## 📌 Project Overview
This project demonstrates an end-to-end retail sales data analysis using SQL. It includes database creation, data insertion, and analytical queries to generate business insights.

The project simulates a real-world retail environment with customers, products, orders, and sales transactions.

---

## 🏗️ Database Design

The database consists of the following tables:

- **Customers** – Stores customer details
- **Products** – Stores product information
- **Orders** – Stores order-level data
- **Order_Items** – Stores item-level transaction details
